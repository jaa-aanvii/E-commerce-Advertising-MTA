# Ecommerce Advertising MTA

Multi-Touch Attribution model combining Markov Chains and Shapley Values for modern e-commerce advertising channels.

## Structure
- src/markov_engine.py: Person A (Data pipeline, Transition Matrices, Removal Effect)
- src/shapley_engine.py: Person B (Coalitions, Shapley Values, Hybrid Integration)
- data/raw/: Raw advertising dataset
